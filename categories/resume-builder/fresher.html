🎓 Fresher Resume Template

Best for: Fresh graduates, 0-1 year experience

📌 Sections to Include

  • Header: Name, Phone, Email, LinkedIn, GitHub
  • Education: College, CGPA, Year (Reverse chronological)
  • Skills: Technical skills, Languages, Frameworks
  • Projects: 2-3 strong projects with tech stack
  • Internships: If any, include achievements
  • Certifications: Relevant ones only
  • Achievements: Hackathons, coding contests

✅ Tips

  • Keep it 1 page maximum
  • Use action verbs (Built, Developed, Implemented)
  • Quantify achievements (e.g., "Improved performance by 30%")
  • Tailor for each job application
  • No "References available upon request" — waste of space
