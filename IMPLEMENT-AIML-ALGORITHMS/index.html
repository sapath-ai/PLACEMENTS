    How to read "Which library for what" on each card

    NumPy only = build the actual math/algorithm yourself, no shortcuts. pandas = fine for loading/cleaning data, never for the algorithm itself. scikit-learn / statsmodels = only used after your version works, to check your numbers are right. PyTorch = used where hand-writing backprop a second time (e.g. for CNNs, Transformers, RL policy networks) would cost you time without teaching you anything new — you've already proven you can do it by hand in earlier tiers.

    Coverage note: this guide prioritizes algorithms worth understanding at the whiteboard-and-machine level: derive the core idea, implement it from first principles, verify it numerically, and understand where it succeeds or fails. It is not literally exhaustive — the full space of published AI/ML algorithms runs into thousands of narrow variants. The roadmap intentionally favors transferable algorithmic understanding over framework-specific engineering.
