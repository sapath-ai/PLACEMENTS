07 · Operating Doctrine

This is an operating system, not a syllabus.

  • Build before collecting. Every learning block must produce code, an experiment, an architecture, a benchmark, a paper artifact or interview proof.
  • Fundamentals outlive frameworks. Learn protocols, distributed systems, retrieval, evaluation and inference deeply enough that frameworks become interchangeable.
  • Agents are systems engineering. Tool use, authorization, sandboxing, durable execution, observability and failure handling matter as much as prompting.
  • MCP is a protocol competency. The July 2026 specification makes scalability, routing, authorization, extensions and long-running work part of the modern target. citeturn0search0
  • Kill shallow breadth. Ten agent frameworks, five vector databases and twenty AI APIs without a reliable shipped system are résumé decoration.
  • Your end state: take an ambiguous business/research problem → design the AI system → build it → evaluate it → deploy it → operate it → optimize it → explain it → defend it.
