Portfolio QUBO Formulation
Minimize: f(x) = xTΣx − μTx + t(1Tx − B)2
where: x ∈ {0,1}n (binary stock selection)
Σ = covariance matrix, μ = expected returns, B = budget (# stocks)
t = penalty factor (must dominate covariance scale)
Ising mapping: x_i = (1 − z_i)/2 where z_i ∈ {−1, +1}
H_C = Σi,j Jij ZiZj + Σi hi Zi

Python — QUBO Construction for Portfolio
import numpy as np
import yfinance as yf

# Fetch real data
tickers = ['AAPL', 'MSFT', 'GOOGL', 'NVDA']
data = yf.download(tickers, period='1y')['Close']
returns = data.pct_change().dropna()

mu = returns.mean().values        # expected returns
sigma = returns.cov().values      # covariance matrix
n = len(tickers)
B = 2                            # budget: pick exactly 2 assets
t = 5.0                          # penalty factor

# Build QUBO matrix Q
def build_qubo(sigma, mu, t, B):
    Q = sigma.copy()
    # Add penalty for budget constraint: t*(sum(x) - B)^2
    # Expanding: t*[sum(x_i^2) + 2*sum_{i
    for i in range(n):
        Q[i, i] += t * (1 - 2*B) - mu[i]
        for j in range(i+1, n):
            Q[i, j] += 2 * t
    return Q

Q = build_qubo(sigma, mu, t, B)
print("QUBO Matrix shape:", Q.shape)
print("QUBO:\n", np.round(Q, 4))

Week 9–10 — QAOA Theory (Deep)
  • Read Farhi, Goldstone & Gutmann (2014) arXiv:1411.4028 — the QAOA paper. Read 3 times. Annotate every equation.
  • Understand the QAOA ansatz: |ψ(β,γ)⟩ = e^{-iβ_p H_M} e^{-iγ_p H_C} ··· e^{-iβ_1 H_M} e^{-iγ_1 H_C} |s⟩
  • Cost Hamiltonian H_C: diagonal in Z basis, encodes the portfolio objective
  • Mixer Hamiltonian H_M: typically Σ X_i (transverse field), drives exploration of the state space
  • Prove: at p=1 and p→∞, QAOA reproduces the adiabatic theorem behavior.
Week 11 — Quantum Amplitude Estimation (Theory)
  • Nielsen & Chuang Ch. 5: quantum phase estimation. This is the foundation for QAE.
  • Understand the theoretical query-complexity result: classical Monte Carlo scales as O(1/ε²) samples while ideal amplitude-estimation methods can achieve O(1/ε) oracle queries. Distinguish query complexity from end-to-end runtime, state preparation, circuit depth, noise, shots, and hardware cost.
  • Iterative QAE (IQAE): removes the need for phase estimation overhead — study Grinko et al. (2021).
  • Derive: how VaR becomes an amplitude estimation problem. What is the "oracle" that must be built?
Week 12 — NISQ Realism & Error Mitigation
  • Read IBM's NISQ era paper (Preskill 2018). Understand: ~50–1000 qubits, no error correction, limited depth.
  • Study zero-noise extrapolation (ZNE): run circuit at multiple noise levels, extrapolate to zero noise.
  • Study probabilistic error cancellation (PEC). Understand the overhead cost.
  • Critical mindset: every paper claiming "quantum advantage" in finance — scrutinize the assumptions. Most are under unrealistic conditions. Know the difference between demonstrated and projected advantages.

Qiskit — QAOA Portfolio Optimizer (Core)
from qiskit_finance.applications import PortfolioOptimization
from qiskit_algorithms import QAOA, NumPyMinimumEigensolver
from qiskit_algorithms.optimizers import COBYLA
from qiskit_optimization.converters import QuadraticProgramToQubo
import numpy as np

# 1. Define the portfolio problem
num_assets = 6
budget = 3             # select exactly 3 assets
penalty = 5.0

portfolio = PortfolioOptimization(
    expected_returns=mu,
    covariances=sigma,
    risk_factor=0.5,     # λ: risk aversion
    budget=budget
)
qp = portfolio.to_quadratic_program()

# 2. Convert to QUBO
converter = QuadraticProgramToQubo()
qubo = converter.convert(qp)

# 3. Classical baseline (exact)
exact = NumPyMinimumEigensolver()
exact_result = exact.compute_minimum_eigenvalue(qubo.to_ising()[0])
exact_x = portfolio.interpret(converter.interpret(exact_result))

# 4. QAOA
optimizer = COBYLA(maxiter=300, rhobeg=0.5)
qaoa = QAOA(optimizer=optimizer, reps=2)   # p=2 layers
qaoa_result = qaoa.compute_minimum_eigenvalue(qubo.to_ising()[0])
qaoa_x = portfolio.interpret(converter.interpret(qaoa_result))

print(f"Exact solution:  {exact_x} | Selected: {np.where(exact_x)[0]}")
print(f"QAOA  solution:  {qaoa_x}  | Selected: {np.where(qaoa_x)[0]}")
print(f"Approximation ratio: {qaoa_result.eigenvalue / exact_result.eigenvalue:.4f}")
